# Assessment Scope

## Overview

This cyber risk assessment was performed against a controlled cybersecurity laboratory built around Check Point Security Gateway R82.

The assessment focuses on translating technical security observations into structured cyber risk scenarios and evaluating the relationship between assets, threats, vulnerabilities or conditions, security controls, technical evidence, and risk treatment.

## Environment

The assessed environment consisted of a VirtualBox-based cybersecurity laboratory containing:

- Check Point Security Gateway R82
- Check Point security management components
- LAB-LAN network segment
- Windows 10 test endpoint
- Security policies and access control rules
- Intrusion Prevention System (IPS)
- Threat Prevention capabilities
- Security logging and monitoring functionality

## In-Scope Security Areas

The assessment considered the following security areas:

- Network access control
- Firewall policy enforcement
- Intrusion Prevention System (IPS)
- Threat Prevention
- SQL Injection protection
- Security logging
- Network segmentation
- Security policy configuration
- Protection database currency and update capability

## Assessment Activities

Activities performed within the defined scope included:

- Identification and classification of relevant assets
- Review of implemented security controls
- Analysis of technical observations and findings
- Collection and mapping of assessment evidence
- Development of cyber risk scenarios
- Likelihood and impact assessment
- Risk scoring using a 5×5 risk matrix
- Definition of risk treatment actions
- Estimation of target residual risk
- Executive-level risk reporting

## Out of Scope

The following activities were outside the scope of this assessment:

- Production infrastructure testing
- Enterprise-wide vulnerability assessment
- Full penetration testing
- Active Directory security assessment
- Cloud security assessment
- Application source code review
- Full SIEM or SOC capability assessment
- Business continuity and disaster recovery testing
- Third-party risk assessment

## Scope Limitation

The assessment was conducted in a controlled laboratory environment.

Findings and risk ratings therefore represent the conditions observed within the defined lab scope and should not be interpreted as the security posture of a production organization.

The project is intended to demonstrate an evidence-based technical cyber risk assessment methodology and the traceability between technical security observations and risk-management decisions.
